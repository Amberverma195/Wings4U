# Category food thumbnails

These are generated category illustrations, not photographs of the restaurant's actual dishes.
Created with the built-in imagegen tool and saved as 192px PNGs with transparency.
Original aspect ratios and alpha were preserved when resizing for mobile.

## Prompt set

Common prompt: Photorealistic restaurant menu category food cutout on a genuinely
transparent background. Square, centered composition with the complete food visible,
approximately 80% subject coverage, even padding, three-quarter front camera,
warm vivid studio lighting, realistic food texture, tiny soft contact shadow.
Recognizable at 48 pixels. No scenery, backdrop, lettering, logos, labels, borders, or UI.
